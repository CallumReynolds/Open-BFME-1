## Structural hypothesis and experiment

The saved body reproduces 720 emitted bytes against 721, with 258 differing non-relocation bytes and one absent byte. Every difference is localized in baseline_alignment.log: the three guard displacements reflect the shorter suffix; the blue load and conversion block at `+0x1C2` through `+0x206` differs in scheduling, byte register, conversion slot and output-pointer lifetime; from retail `+0x20A` onward the instruction sequence agrees at a one-byte displacement. The earlier claim that only a register spelling remained was insufficient to exclude a source loop.

The new hypothesis is that explicit channel statements lost the induction structure that drives unrolling and pointer lifetimes. An ascending sample-channel loop combined with a descending output pointer, or a descending output-channel loop combined with ascending sample pointers, should let the compiler see the three traversals together. Failure to move the early MOVZX and output-pointer load would refute this mechanism. A descending integer loop alone first reaches 721 bytes with 62 differences, independently demonstrating that loop structure changes the disputed prefix. Shifted counters and an output pointer explore the changed graph exposed by that result.

The final form uses `for (Int channel = 2; channel >= 0; --channel, ++top, ++bottom)` and the canonical Vector3 indexing operator. Iteration two writes blue at output offset 8 from sample offsets 0 and 3; iteration one writes green at output offset 4 from sample offsets 1 and 4; iteration zero writes red at output offset 0 from sample offsets 2 and 5. Both sample pointers advance within their pixel rows. The compiler fully unrolls the loop, hoists `movzx esi,[eax+edi+3]` at `+0x1C2`, loads the output pointer at `+0x1CE` and uses its dead argument slot for the integer conversions. An independent ascending-loop form with a descending output pointer produces the same bytes. The final source uses the sample-pointer form and retains all existing descriptive names.

Complete trial sources, emitted bodies, compiler object paths and unedited probe outputs are retained under build/r001a3d30_20261015/.
