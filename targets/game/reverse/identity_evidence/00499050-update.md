## Source shape and refutation tests

The bank's caller-local conditional handle lets the compiler eliminate the saved-pointer retest. Reading the nullable virtual result through a member accessor preserves retail's instructions at +0xA1 through +0xB9, including the saved ESI test at +0xB3. The source-only accessor is named getBufferHandle00499050 and is fully inlined; it is not a recovered external identity. The raw comparison is build/wvm-update/02-member-nullable-accessor.log.

Retail decrements the play type at +0xBD and branches to the mode-four call for value 1. Other values call slot +0x18 with mode zero. The second decrement at +0xC9 selects the pause path for value 2; every other value follows the stop path after the flags and zero-index tests. The bank instead tested for value 0 after the virtual calls. Separate switch arms with an explicit default stop path reproduce both decrements, the shared mode-zero call, and both bit-zero tests. The default arm is required for the witnessed behavior of other enum values. See build/wvm-update/01-switch-flags.log and build/wvm-update/04-switch-default-stop.log. The final cleaned source also reproduces all 301 masked bytes in build/wvm-update/07-final-source.log.

The recovery would be refuted by an outgoing target branch omitted from this extent, a value-copy field beyond the two decoded dwords, a hidden parameter or receiver adjustment at these call sites, or a strict relocation mismatch. A different concrete movie implementation is not assigned an identity by this evidence.
