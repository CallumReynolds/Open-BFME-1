## Retry hypothesis and measurements

The saved reconstruction was reproduced before editing. It emitted 1,604 bytes, with 1,119 non-relocation byte differences and 32 normalized structural differences. Its 0.934 header described instruction shape rather than byte equality. The raw result is build/finish-007b6520/bank-probe.log. All earlier records were retrieved into build/finish-007b6520/history.log.

The initial hypothesis was that native static initialization, native render-state inline boundaries, and the actual lifetimes of loop values would explain the entry and register differences. An unchanged complete candidate after those corrections would refute the hypothesis. Native static objects alone did not improve the structure. Decoding instead found that the bank cached the manager's list head across calls and reloaded each current texture after flushing. Retail reloads the head and saves both current textures before the call. Correcting those operations and supplying the real render-state inline structure produced a complete 1,640-byte candidate. A typed read of the settings byte removed the first remaining scratch-register difference.

The last residue was removed by defining the two current texture pointers before the copied type and assigning the new cached textures before the cached type. build/finish-007b6520/gd-order-3-probe.log records the first exact probe. The final source also adopts the existing RenderObjClass, RenderInfoClass, StringClass, WWMath and validated Direct3D declarations. build/finish-007b6520/address-inline-probe.log records the final source's exact masked probe. build/finish-007b6520/final-scoped-gate-v2.log records passing strict function, string, constant and recorded-DIR32 checks. No callee pin was added, and the generated dump source was not edited.

The bank's descriptive `head` spelling remains a narrowly scoped preprocessor alias to the manager's current `m_1c` field. This preserves the old name while making every read fresh. Reintroducing an ordinary persistent head local changes register allocation and misses retail; the raw rejected results are build/finish-007b6520/retained-head-probe.log and build/finish-007b6520/scoped-head-probe.log. The alias emits the same bytes as direct field reads. The per-body inline render-state helper keeps an address token and is marked as absent as a separate retail body from this translation unit.

Other rejected experiments are retained with their source and unedited probe output in build/finish-007b6520/. They include ordinary and forced inline boundaries, adjacent declaration and store choices, signed and enum type views, pointer and record temporaries, receiver aliases, loop forms, argument-copy rotation, explicit stack writes, and final-string wrappers. Compiling the actual matched flush source beside the caller did not improve the remaining residue; build/finish-007b6520/helper-copy-probe.log independently verifies that copied 3,124-byte helper. These rejected forms are not part of the recovery.
