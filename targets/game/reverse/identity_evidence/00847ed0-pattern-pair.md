The body at 0x00847ED0 is 31 bytes. It begins after eight decoded INT3 bytes, returns at +0x1E and is followed by INT3 padding. It has no branches, calls, exception handler or stack arguments. It receives two four-byte output groups in ECX and EAX, and stores byte values 2, 3, 0 and 4 into offsets 0 through 3 of each group. It reads no payload fields and makes no ownership or return-value promise. See build/donor-port/00847ed0-extent.log and build/donor-port/00847ed0-callees.log.
