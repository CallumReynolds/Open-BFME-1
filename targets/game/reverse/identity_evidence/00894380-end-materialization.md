This closes the old two-byte tick-helper residue without claiming a new recovery of an already matched body.

The productive hypothesis grouped the traversal's current pointer, end pointer and byte count into a local aggregate. This tests the lifetime of the copied end value across scalar replacement, while preserving the decoded loads and comparisons. It would be refuted if the aggregate added memory operations, lost the repeated array-pointer read, or did not improve the target. The complete trial build/apt00894380/041-aggregate-pod.cpp emits 728 bytes with 125 differences; its first difference is at +0x58 and the final return layout aligns with retail. ## Rejected hypotheses and remaining mismatch

The baseline's complete per-byte location map is build/apt00894380/difference-map.tsv, its grouped ranges are build/apt00894380/difference-ranges.log and its aligned decoded instructions are build/apt00894380/aligned-instructions.log. These distinguish relocation-layout drift from actual source operations. The initial end calculation uses mov/add in retail and lea plus alignment in the candidate. The second traversal repeats that difference and chooses different scratch registers. That changes the owner-pointer load, flag scratch register and short EAX forms for later global loads. Most of the raw byte differences are the resulting instruction displacement and relocation-site shifts. The switch default also bypasses the list reload in retail.
